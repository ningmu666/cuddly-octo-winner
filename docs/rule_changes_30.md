# Seedance 2.5的30秒规则同步修改清单

依据2026年10月17日上传的30秒规则，参照15秒末镜修订版核对。以下为局部修订建议，不包含完整专用智能体指令。章节定位以该上传版本为准；修改后需搜索全文残留的无条件“严格30秒”“恰好30秒”“写满30秒”“素材时长不足”等表述，逐处判断，不能机械全局替换正常30秒示例。

## 统一定义（第一章第3条，替换时长要求）

除全剧最后一个主分镜外，每个主分镜固定30秒。只有已按原顺序完整消费全剧最后剩余内容、后面没有未消费剧情的主分镜，才允许实际总时长T满足0＜T≤30秒。T由各子分镜的合法自然时长相加确定，标题填写实际数字，子分镜合计必须严格等于标题T。不得用静止等待、空镜、重复反应、慢动作、额外台词或新增剧情补满30秒。文件尾、批尾、主分镜内最后一个子分镜均不自动获得全剧末镜资格。无法确认剧终时，不得按短末镜准入。原篇幅上限保持不变。

## 逐处修改

| 位置 | 应同步执行的条款 |
| --- | --- |
| 全局优先级：时长准确 | 非全剧末镜30秒；真正全剧末镜按实际T核算。 |
| 第一章：镜数目标、内容不足、对白容量及逐子计时公式 | 常规30秒目标保留；短末镜按剩余有效节拍决定镜数。仍有后文时吸收相邻剧情；确已全部消费完则自然结束。合计以本镜适用总时长为准。 |
| 第一章第13条：批次 | 非末批10镜，终局末批1—10镜；非终局批尾固定30秒，恰为全剧末镜时可短。全局编号、状态及游标跨批不重置。 |
| 第一章：标题格式；第九章输出样板 | 改成`【主分镜 X】（总时长：T秒）`。实际输出X、T必须为数字；非末镜T=30，末镜可例如22。人物主体描述若写“本主分镜30秒内”也改为实际时长或不带固定秒数。 |
| 第二章第3节：逐镜规划与写入 | 每镜规划时判断终局资格；登记实际T与是否全剧末镜。终局写入并入账后立即停止，不创建0秒镜或空批次。 |
| 第二章第4节：30秒边界与终局预检 | 删除“有不足30秒尾段则当前镜暂不准入、共同重排为完整30秒、无法组成则报告素材时长不足”的要求。合格30秒前镜正常准入，剩余尾段另成实际T末镜；全剧本来不足30秒时可只有一镜。只有真实无法合法呈现的约束冲突才报告，不能仅因末镜短而报告不足。 |
| 第二章第5节：批尾 | 批尾只决定换文件，不决定剧情落点；仍有原剧情则30秒，真剧终则按T停止。 |
| 第二章第6节：滚动返工 | 每个受影响镜重新判定终局；传播至状态收敛或新全剧终点。追加剧情使旧短末镜变中途镜时，撤销旧资格并重排，非末镜恢复30秒，废止多余旧镜/旧终局标记。 |
| 第二章第7节：时长与节奏准入门 | 非末镜合计30秒；末镜已确认内容全部消费完，合计0＜T≤30秒；两者均与标题一致，不拖拍、不强行加速、不补无意义镜头。 |
| 第六章：跨主分镜连续性台账 | 新增实际T、是否全剧末镜；真正末镜下一未消费游标写“全剧结束”。返工后撤销失效终局记录。 |
| 第七章：动作密集镜数目标 | 常规镜保留目标；短末镜按实际必要动作确定镜数，不重复动作/技能来凑30秒。 |
| 第九章：字段规则及时间表 | 子镜时长支持小数；核算0至实际T的连续时间表；合计等于实际标题，不能仅改标题。 |
| 第十章：30秒完整示范说明 | 保留示范的30秒计时，补充“这是常规示例；全剧短末镜不照例强补30秒”。 |
| 第十一章B通用准入门、批次交付审计 | 将无条件合计严格30秒改为上述适用规则。10k批尾仍有剧情时30秒，若恰为剧终则核对实际T和终局台账；批次不产生终局资格。 |

修改后最低验收：30秒常规镜通过；已确认22秒全剧末镜通过；22秒中途镜和仅因文件结束的22秒镜不通过。即使末镜编号为10也同样按终局声明判定；不得为了文件收满10镜而添加剧情。
